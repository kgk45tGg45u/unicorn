# What changed in each release

In plain words, for members and operators. A release that carries an approved change to the hard frame names its ticket (`T-…`) here, and an operator records it with `record_release` (P07.T06). Version tags look like `v0.9.0`. Every release goes to staging first (deploy/README.md, "Releases").
